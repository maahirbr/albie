# Albie ⛳

**A pocket caddie who has already walked the course a thousand times.**

Open source, built for the love of golf. Albie turns real course knowledge -
official hole guides, tour coverage, caddie wisdom, OpenStreetMap hole
geometry - into situational calls: one club, one target, one warning.

**Try it: https://maahirbr.github.io/albie/**

Courses in this build: The Old Course (St Andrews), Carnoustie Championship,
Delhi Golf Club (Lodhi), DLF Golf & CC (Gary Player). Everything runs in your
browser; your profile and rounds stay on your phone.

This page hosts the built app. The knowledge pipeline (ingestion, per-tee
scorecards, geometry extraction, decision engine) lives in the main project,
opening up as it's cleaned for release. Course data carries source tags and
honest confidence levels - see the trust card in the app.
